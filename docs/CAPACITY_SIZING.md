# Capacity sizing guide

The single authoritative sizing analysis is [report.md, Section 10](../report.md#10-conditional-sizing-for-501000-call-legs), using the completed resumable experiment.

It contains admission and processing-demand equations, CPU/RAM assumptions, 30% planning headroom, language-aware demand and conditional estimates for 50, 100, 200, 500 and 1,000 call legs. These are planning scenarios, not measured fleet capacity or predicted latency guarantees.

Prefix-only coefficients are retained solely in [archived prefix sizing](archive/prefix-sizing.md).
